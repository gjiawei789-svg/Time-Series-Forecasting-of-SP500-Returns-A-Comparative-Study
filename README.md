# SP 500 
## S&P 500 收益率时间序列预测：AR/ARMA/GARCH 与 LSTM 模型比较研究

## 1. 项目简介

本项目以 **1980 年 1 月 3 日至 2010 年 8 月 31 日** 的 **S&P 500 指数日收盘价**为研究对象，基于对数收益率序列构建时间序列预测模型，并比较传统计量经济学模型与 LSTM 神经网络的预测表现。

研究流程包括：

1. 数据预处理与平稳性检验；
2. 使用 ACF、PACF、EACF、AIC、BIC 识别 AR / ARMA 均值模型；
3. 对残差进行 Ljung-Box 检验与 ARCH-LM 检验；
4. 发现条件异方差后，引入 GARCH(1,1) 与 Student-t 分布；
5. 建立 AR-GARCH、ARMA-GARCH 模型；
6. 构建 LSTM 模型作为非线性对比方法；
7. 比较样本内拟合与样本外预测性能。

**关键词**：Time Series Forecasting, S&P 500, AR Model, ARMA Model, GARCH Model, LSTM, Conditional Heteroscedasticity, Volatility Clustering

## 2. 数据说明

| 项目 | 内容 |
|---|---|
| 研究对象 | S&P 500 指数日收盘价 |
| 时间范围 | 1980-01-03 至 2010-08-31 |
| 样本量 | 报告中有 **7,737** 与 **7,736** 两种表述，复现时需核对 |
| 建模对象 | 对数收益率序列 |
| 数据变换 | 原始价格 \(P_t\) 取自然对数后一阶差分，得到对数收益率 \(r_t = \Delta \ln P_t\) |
| 样本划分 | 前 80% 为训练集，后 20% 为测试集 |
| 划分方式 | 按时间顺序划分，所有模型使用相同训练集与测试集 |

平稳性检验结果：

| 类型 | Dickey-Fuller 统计量 | p 值 |
|---|---:|---:|
| 原始数据 | 0.2943 | 0.7101 |
| 对数数据 | 2.0564 | 0.99 |
| 对数收益率 | -66.2506 | 0.01 |

结论：原始价格与对数价格均不平稳；对数收益率序列在 1% 显著性水平下平稳，满足后续建模假设。

## 3. 方法概述

### 3.1 平稳性与模型框架

- 使用 ADF、PP 检验判断平稳性；
- 使用 ACF、PACF、EACF 初步识别模型阶数；
- 使用 AIC / BIC 选择均值模型；
- 对残差进行 Ljung-Box 检验和 ARCH-LM 检验；
- 若存在条件异方差，则引入 GARCH 模型。

### 3.2 计量经济学模型

- **AR(p)**：自回归模型；
- **ARMA(p,q)**：自回归滑动平均模型；
- **GARCH(1,1)**：广义自回归条件异方差模型；
- **Student-t 分布**：用于刻画金融收益率的肥尾特征。

软件与库：

- R 语言；
- `forecast` 包：ARIMA / ARMA 设定；
- `rugarch` 包：GARCH 波动率建模。

### 3.3 LSTM 模型

- 框架：Python / Keras / TensorFlow；
- 预处理：MinMaxScaler 标准化到 [0,1]；
- 架构：两层堆叠 LSTM，每层 50 个单元，后接全连接层；
- 正则化：Dropout = 0.2；
- 优化器：Adam；
- 损失函数：MSE；
- 可训练参数：30,651。

> 注意：报告在 LSTM 窗口设置上存在不一致。  
> 3.2.2 节写窗口大小 \(\omega=1\)，以保持与 AR(1) 可比；  
> 4.6 节写使用 60 天回溯窗口 \(T=60\)。复现时需统一。

### 3.4 评估指标

- MSE：均方误差；
- RMSE：均方根误差；
- MAE：平均绝对误差；
- Ljung-Box 检验：残差自相关；
- ARCH-LM 检验：残差条件异方差；
- QQ 图：残差分布诊断；
- AIC / BIC：模型选择。

> 注意：GARCH 类模型的 AIC 与均值模型不可直接比较；LSTM 的 AIC 也因参数量巨大而失去跨模型比较意义。

## 4. 模型与主要结果

### 4.1 模型性能汇总

| 模型 | 均值结构 | 方差结构 | 分布 | 样本内 AIC | 样本外 MSE | RMSE | MAE | 主要结论 |
|---|---|---|---|---|---|---|---|---|
| AR(4) | AR(4) | 常数方差 | 未特别说明 | -38648.03 | 0.000207884 | 0.014418 | 0.008986 | 简单可解释，但忽略波动率 |
| AR(4)-GARCH(1,1) | AR(4) | GARCH(1,1) | Student-t | 约 -6.5791* | 0.000208051 | 0.014424 | 0.00898 | 捕捉波动率，诊断较好 |
| ARMA(2,1) | ARMA(2,1) | 常数方差 | 未特别说明 | -38649.97 | 0.000207892 | 0.014418 | 0.008986 | 灵活，但存在参数冗余 |
| ARMA(2,1)-GARCH(1,1) | ARMA(2,1) | GARCH(1,1) | Student-t | 约 -6.5798* | 0.000208064 | 0.014424 | 0.008980 | 均值-方差完整，但诊断略逊 |
| LSTM | 两层 LSTM | 无显式方差方程 | - | 5579.99* | 0.000210328 | 0.014503 | 0.009075 | 非线性建模，但未显著优于传统模型 |

\* GARCH 与 LSTM 的 AIC 与线性均值模型不可直接比较。

### 4.2 AR(4) 模型

估计结果：

\[
r_t = 0.0004 + 0.0211r_{t-1} - 0.0321r_{t-2} - 0.0287r_{t-3} - 0.0193r_{t-4} + \epsilon_t
\]

诊断结果：

- Ljung-Box 检验 p 值 = 0.7517，残差无显著自相关；
- ARCH-LM 检验 p 值 < 2.2e-16，存在显著条件异方差；
- QQ 图两端偏离，存在偏态与肥尾。

结论：AR(4) 能刻画均值结构，但不能处理波动率聚集。

### 4.3 AR(4)-GARCH(1,1) 模型

均值方程：

\[
y_t = 0.000548 + 0.0228y_{t-1} - 0.0203y_{t-2} - 0.0389y_{t-3} - 0.0221y_{t-4} + \epsilon_t
\]

方差方程：

\[
\sigma_t^2 = 1e^{-6} + 0.0476\epsilon_{t-1}^2 + 0.9475\sigma_{t-1}^2
\]

创新分布：

\[
\epsilon_t \sim t(6.50, 0, \sigma_t^2)
\]

关键参数：

- ARCH 项 \(\alpha_1 = 0.0476\)；
- GARCH 项 \(\beta_1 = 0.9475\)；
- \(\alpha_1 + \beta_1 = 0.9951\)，波动率冲击衰减缓慢，具有长记忆性；
- 自由度 \(v = 6.5\)，表明收益率具有肥尾特征。

诊断结果：标准化残差通过加权 ARCH-LM 检验，GARCH(1,1) 成功过滤波动率聚集。

### 4.4 ARMA(2,1) 模型

估计方程：

\[
y_t = 0.0004 + 0.7092y_{t-1} - 0.0494y_{t-2} - 0.6880\epsilon_{t-1} + \epsilon_t
\]

问题：

- AR(1) 系数 0.7092 与 MA(1) 系数 -0.6880 大小接近、符号相反；
- 存在潜在参数冗余与过度参数化；
- Ljung-Box 检验 p 值 = 0.8572，残差为白噪声；
- ARCH-LM 检验 p 值 < 2.2e-16，仍存在条件异方差。

结论：增加均值模型复杂度不能消除异方差。

### 4.5 ARMA(2,1)-GARCH(1,1) 模型

均值方程：

\[
y_t = 0.000554 + 0.7949y_{t-1} - 0.0520y_{t-2} - 0.7727\epsilon_{t-1} + \epsilon_t
\]

方差方程：

\[
\sigma_t^2 = 1e^{-6} + 0.0472\epsilon_{t-1}^2 + 0.9480\sigma_{t-1}^2
\]

创新分布：

\[
\epsilon_t \sim t(6.47, 0, \sigma_t^2)
\]

诊断结果：

- 方差参数稳定，\(\beta_1 \approx 0.948\)；
- 标准化残差通过加权 ARCH-LM 检验；
- 但均值方程参数不稳定，残差诊断略逊于 AR(4)-GARCH(1,1)。

结论：ARMA-GARCH 增加了复杂性，但样本外预测改进有限，因此不是最优选择。

### 4.6 LSTM 模型

LSTM 结构：

- 输入层；
- LSTM 层 1：50 单元，返回序列；
- Dropout：0.2；
- LSTM 层 2：50 单元；
- Dropout：0.2；
- Dense 层：1 个输出；
- 总参数：30,651。

性能：

- AIC：5579.99，但为参数量惩罚导致的数学伪影；
- MSE：0.000210328；
- RMSE：0.014503；
- MAE：0.009075。

诊断结论：

- 训练损失与验证损失接近，Dropout 抑制了过拟合；
- LSTM 能捕捉收益率均值回归特征；
- 但持续低估极端异常值，表现出“衰减效应”；
- 样本外预测未显著优于 AR 或 AR-GARCH 模型。

---

## 5. 主要结论

1. **收益率条件均值可预测性较弱**：各模型在样本外点预测误差上差异很小。
2. **GARCH 类模型的主要优势在波动率刻画**：能提供动态置信区间，更符合金融风险描述。
3. **LSTM 未显著优于传统统计模型**：在日度金融数据的高噪声环境下，复杂深度学习模型未必稳定超越简洁统计模型。
4. **AR(4)-GARCH(1,1) 被确定为最优模型**：在简洁性、稳健性和诊断有效性之间取得较好平衡。
5. **ARMA-GARCH 存在参数冗余与识别不稳定问题**：增加均值结构复杂度并未带来明显预测提升。
6. **残差诊断与假设检验至关重要**：金融时间序列建模不应只追求模型复杂度，而应匹配数据特性与理论假设。

## 6. 复现环境建议

### R 环境

- R 语言；
- `forecast`：ARIMA / ARMA 建模；
- `rugarch`：GARCH 建模；
- 可配合 `tseries`、`urca` 等进行 ADF / PP 检验。

### Python 环境

- Python 3.x；
- TensorFlow / Keras；
- NumPy；
- pandas；
- scikit-learn；
- Matplotlib。

### 建议运行流程

1. 读取 S&P 500 日收盘价数据；
2. 计算对数收益率；
3. 进行 ADF / PP 平稳性检验；
4. 绘制 ACF / PACF；
5. 使用 R 估计 AR、ARMA、AR-GARCH、ARMA-GARCH；
6. 进行 Ljung-Box、ARCH-LM、QQ 图诊断；
7. 使用 Python/Keras 训练 LSTM；
8. 在相同测试集上计算 MSE、RMSE、MAE；
9. 汇总结果并绘制预测图与损失曲线。
